## Separate development identity

The development application is configured to coexist with a working upstream
installation:

- product: **Luna Ultra Webcam Dev**
- bundle identifier: **io.github.defib-tde.luna-ultra-webcam-dev**
- version: **0.3.2-1** (numeric prerelease required by Windows MSI)
- release channel: **webcam-dev**
- auto-updater: **disabled**

The Settings screen displays the exact prerelease version and source commit.
Confirm those values before recording a hardware test.

## Prerequisites

Install Bun, Rust, and the Tauri prerequisites for your operating system. CI
currently pins Bun 1.4.2 and Rust 1.99.0.

On Windows, use the MSVC Rust target and install Microsoft C++ Build Tools and
WebView2 as required by Tauri. Windows packaging also requires **64-bit Python
3.11 or newer** and internet access to build the bundled video engine. Installed
users do not need Python, Git, Bun, Rust or FFmpeg.

## Build locally

```bash
git clone https://github.com/Defib-TDE/insta360-luna-ultra-desktop.git
cd insta360-luna-ultra-desktop
git switch feature/webcam-bridge
bun install --frozen-lockfile
bun run build
```

Generated bundles are written under **src-tauri/target/release/bundle/**.
Locally built artifacts are for development and hardware testing only.

Before installing a Windows bundle:

1. leave the working upstream application installed;
2. confirm the generated product is named **Luna Ultra Webcam Dev**;
3. confirm its executable and uninstall entry are distinct;
4. record the app version and commit shown in Settings;
5. do not publish or upload the installer.

## Run without bundling

```bash
bun install --frozen-lockfile
bun run dev
```

The browser-only UI can be started with **bun run ui:dev**, but browsers cannot
open the camera's raw TCP control session. Real camera and webcam testing
requires the Tauri desktop application.

## Webcam output

Open **Studio** and follow its setup checklist. Install OBS Studio if the camera
driver is missing, connect Luna, choose a profile and click **Start webcam**.
Choose **OBS Virtual Camera** in your destination; keep OBS’s own virtual-camera
publisher stopped. The [Studio setup guide](https://github.com/Defib-TDE/insta360-luna-ultra-desktop/blob/feature/webcam-bridge/docs/STUDIO_SETUP.md)
covers the integrated flow and guided streaming. The external bridge remains a
diagnostic option.

Keep camera mode fixed during the initial baseline. Record hardware observations
separately from simulated mock-server or generated-stream results.
